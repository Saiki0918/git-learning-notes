## 知识体系

1. **基础环境搭建** — 安装配置、SSH 密钥、仓库初始化
2. **日常开发流程** — 增删改查、暂存区、版本回退
3. **常见异常处理** — 冲突解决、误删恢复、游离 HEAD
4. **分支管理策略** — 分支创建切换、合并策略、分支模型
5. **团队协作规范** — Pull Request、Code Review、提交规范
6. **高级技巧** — Rebase、Cherry-pick、Stash、标签管理
